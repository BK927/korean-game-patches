# KUKULA Korean recovery glossary

The source basis is the installed Simplified-Chinese key table plus the `GameLang.cn_lang` story map; Traditional Chinese and prior English/Japanese extracts were used as cross-checks.

- **库库拉** → **쿠쿠라** — character name
- **魅魔** → **서큐버스** — succubus
- **恶魔** → **악마** — demon
- **契约** → **계약** — pact/contract
- **主人** → **주인** — master
- **舍友** → **룸메이트** — roommate
- **存档/读档** → **저장/불러오기** — save/load UI
- **场景** → **장면** — scene; not 시나리오
- **镜头/相机** → **카메라** — camera; not 렌즈/샷
- **贴图/纹理** → **텍스처** — texture
- **材质** → **재질** — material
- **表情** → **표정** — expression; not 액션
- **环境声效** → **환경음** — ambient sound; not 배경음악
- **停止播放/暂停播放** → **재생 중지/일시 정지** — distinct controls
- **滤色/混合添加/溶解** → **스크린/가산 혼합/디졸브** — blend/effect terms
- **[@s6]** → **[@s6]** — preserve runtime placeholder exactly

## Voice

- 쿠쿠라: 친근하고 장난스러운 반말.
- 플레이어/서술: 자연스러운 중립 문장.
- `[@s6]` 같은 런타임 placeholder는 그대로 보존.
