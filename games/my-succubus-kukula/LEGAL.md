# Legal and distribution notice

This is an unofficial community localization recovery package for the Steam
game **My succubus Kukula**. It is not affiliated with or endorsed by the
developer, publisher, Steam, or Valve.

The package contains translation field updates, patch metadata, helper code,
glossary/QA records, and runtime notes only. It deliberately excludes the
game's original `script.js`, language JSON files, images, audio, executable,
and other original assets. Users must obtain the game through a lawful copy
and apply the patch to their own installation.

Redistribute this package only where the translation text and helper metadata
are legally permitted. Do not bundle or mirror the original game files. The
patch is provided without warranty; keep the generated backups and use Steam's
file-integrity check to recover if a later game update changes the base files.
