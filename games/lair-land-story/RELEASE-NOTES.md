# Lair Land Story Remake Edition 한글 패치 v0.1.0-rc1

제작사의 번체중문판(`cnh`)을 원문으로 삼아 스토리, UI, 시스템 문구를 한국어화한 첫 릴리스 후보입니다. 영어판은 번역 원문으로 사용하지 않았습니다.

## 포함 내용

- 스토리·대사·선택지 14,965개
- 메뉴·아이템·도움말 UI 748개
- 코드 내부 시스템 문구 610개
- 한국어 글꼴, 메뉴 이미지 26개, 제목 이미지 2개
- 인명·지명·상태명과 핵심 용어 통합 검수

## 검증

- 전체 16,323개 번역 단위 자동 검사 통과
- 수정된 Unity 자산 29개 구조 재검사 통과
- 33개 변경 파일의 설치·검증·복원 왕복 시험 통과
- 원본 게임 파일 대신 xdelta 변경분만 배포

모든 분기와 엔딩을 직접 플레이하는 전 경로 검증은 아직 완료되지 않아 프리릴리스로 배포합니다.
