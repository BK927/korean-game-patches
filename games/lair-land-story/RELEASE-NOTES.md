# Lair Land Story Remake Edition 한글 패치 v0.1.1-rc1

제작사의 번체중문판(`cnh`)을 원문으로 삼아 스토리, UI, 시스템 문구를 한국어화한 릴리스 후보입니다. 영어판은 번역 원문으로 사용하지 않았습니다.

이 버전은 `v0.1.0-rc1`의 글꼴·스토리 파일 문제를 수정하고 설정 화면 이미지까지 한국어화한 교체 릴리스입니다.

## 포함 내용

- 스토리·대사·선택지 14,965개
- 메뉴·아이템·도움말 UI 748개
- 코드 내부 시스템 문구 610개
- 한국어 글꼴, 메뉴 이미지 26개, 제목 이미지 2개, 설정 이미지 13개
- 인명·지명·상태명과 핵심 용어 통합 검수

## 수정 사항

- 일부 화면에서 한국어가 빈 글자로 표시되던 글꼴 메타데이터 불일치 수정
- 프롤로그 이후 진행을 막을 수 있던 스토리 TSV 물리 줄바꿈 오류 수정
- 설정 화면 제목과 8개 항목, 하위 설정 제목을 한국어 이미지로 교체
- 실제 게임에서 인게임 대사와 설정 화면 한국어 출력 확인

## 검증

- 전체 16,323개 번역 단위 자동 검사 통과
- 수정된 Unity 자산 42개 구조 재검사 통과
- 46개 변경 파일의 설치·검증·복원 왕복 시험 통과
- 원본 게임 파일 대신 xdelta 변경분만 배포

모든 분기와 엔딩을 직접 플레이하는 전 경로 검증은 아직 완료되지 않아 프리릴리스로 배포합니다.
