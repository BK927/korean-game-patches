# Absent in the Rain 한글 패치 v1.0.0

일본어 원문을 기준으로 게임에 한국어 언어를 추가하는 비공식 팬 패치입니다. 기존 6개 언어 옆에 7번째 언어 슬롯을 만들기 때문에 다른 언어의 동작에는 영향을 주지 않습니다.

## 번역 범위

- 본편과 모든 분기, EX 시나리오의 서술·대사 1,841줄 전체
- 화자 이름표 1,132곳
- 타이틀·게임 내 메뉴·환경 설정·저장·불러오기·기록 화면
- 감상 화면의 장면 14개와 줄거리, 음악 8곡 제목
- 선택지 2종, 언어 선택 버튼, 보너스 개방 알림
- 우산 타이틀 로고 `비가 되어 / 사람을 벗다`

번역은 하루야의 1인칭 서술, 유키노와의 관계, 우요의 고풍스러운 말투를 장면 전체에서 이어지도록 다듬었습니다. 일본어 원문을 우선하고 영어·중국어판은 중의적인 문맥을 확인하는 용도로만 참고했습니다.

## 설치

1. `AMEHAZU_KoreanPatch_v1.0.0.zip`을 받아 원하는 폴더에 완전히 풉니다.
2. 게임을 종료합니다.
3. `INSTALL_KOREAN_PATCH.bat`을 실행합니다. 게임 폴더를 자동으로 찾지 못하면 경로를 입력합니다.
4. 게임을 실행하고 타이틀 화면 왼쪽 위 `言語 / Language`에서 `한국어`를 선택합니다.

설치 프로그램은 대상 파일 70개의 원본 SHA-256을 모두 검사하고, 덮어쓰는 원본 13개를 `*.korean-patch-backup`으로 보관한 뒤 적용 결과를 다시 확인합니다. 이미 설치되어 있으면 아무것도 바꾸지 않고 종료합니다.

## 원상 복구

`RESTORE_ORIGINAL.bat`을 실행하면 원본 13개를 되돌리고 패치가 추가한 파일 57개를 지운 뒤 결과를 검사합니다. Steam의 파일 무결성 검사로도 복구할 수 있습니다.

## 알려진 제한

- OP·ED 영상은 자막이 영상 자체에 새겨져 있어 일본어판을 그대로 사용합니다.
- 칠판 손글씨 낙서는 원작 미술을 보존하고 이름 라벨만 아래에 덧붙였습니다. 영어판과 같은 방식입니다.
- 엔진이 직접 그리는 저장 슬롯 날짜 등 일부 문자열은 원래 형식을 따릅니다.
- 게임이 업데이트되어 대상 파일이 바뀌면 새 버전 대응이 필요합니다.

## 배포 형식과 권리 관계

게임 원본 파일은 포함하지 않습니다. 원본에서 파생된 파일은 사용자가 보유한 정품 파일과 VCDIFF 변경분으로 재구성하며, 직접 조판한 한글 이미지만 그대로 제공합니다. 한글 조판에는 게임에 이미 들어 있는 Noto Serif CJK KR을 사용하므로 글꼴 파일을 따로 추가하지 않습니다.

정품 보유자를 위한 비공식 팬 패치이며, 개발사의 허락을 받아 제작한 것이 아닙니다. 게임과 상표, 시나리오를 포함한 모든 권리는 개발사 DIORAMA에 있습니다. 권리자의 요청이 있으면 관련 자료를 조정하거나 제거합니다.
