# Absent in the Rain 한글 패치 v1.0.2

프롤로그 종료 후 다음 장면으로 진행되지 않던 문제를 고친 필수 핫픽스입니다.

## 변경 사항

- 프롤로그 끝에서 재생되는 OP 영상의 파일명이 `undefined`로 잘못 생성되던 문제를 수정했습니다.
- 한국어판은 게임에 포함된 일본어 OP 영상 `amehazuOP3.webm`을 정상 재생한 뒤 장면 2로 넘어갑니다.
- 빌드 결과에 정의되지 않은 리소스 참조가 들어가면 배포본 생성을 중단하도록 검증을 추가했습니다.

번역문과 UI 자산은 v1.0.1과 동일합니다. 기존 v1.0.1 사용자는 v1.0.2를 그대로 덮어 설치할 수 있습니다.
