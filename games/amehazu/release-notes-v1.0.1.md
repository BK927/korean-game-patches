# Absent in the Rain 한글 패치 v1.0.1

v1.0.0의 전체 번역과 설치·복구 기능은 그대로 유지하면서, 타이틀 화면의 우산 로고를 다시 디자인한 소규모 UI 개선판입니다.

## 변경 사항

- 우산 위 `비가 되어`, 아래 `사람을 벗다`가 즉시 읽히도록 글자 형태와 배치를 재구성했습니다.
- 원작의 가늘고 불안정한 문학·괴담 분위기를 손글씨풍 한글 획으로 옮겼습니다.
- 우산 실루엣과 중앙 손잡이, 흑백 색조는 유지했습니다.
- 미리보기 배경을 제거하고 실제 투명 알파 채널로 복원했습니다.
- 게임 자산의 원래 크기인 `389×256`을 유지했습니다.

본편·모든 분기·EX 시나리오 1,841줄과 화자 이름표 1,132곳은 v1.0.0과 동일하게 전체 번역되어 있습니다.
