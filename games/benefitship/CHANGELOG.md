# 변경 기록

## 0.1.0-rc1 - 2026-08-31

- 최신 원문과 정확히 대응하는 대사·내레이션 번역 블록 1,569개와 UI·설정·크레딧 문자열 102개 한국어화
- 이전 합본의 중복 번역 ID 13개와 최신판에 없는 고아 번역 ID 1,235개 제거
- 문맥·의미 오류 69건, 실제 문자열 102곳 직접 교정
- 기존 중단 패치의 문맥, 말투, 고유명사와 용어 일관성 재검수
- 한국어 언어 선택 항목 추가
- 한국어 로고 누락 시 공식 기본 로고를 사용하는 안전 대체 처리 추가
- 옵션 상단 탭의 한글 네모 표시 수정
- 크레딧 문자열을 번역 체계에 연결
- 원본 해시 검사, 자동 백업, 설치 확인, 반복 설치 판정, 복구 기능 추가
- 메인 메뉴, 옵션, 새 게임 첫 장면 실제 실행 검증
