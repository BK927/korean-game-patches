# Tiny Shadows Interwoven Hearts — runtime observations

The final release was installed to the user's Steam directory only for a
short, read-only UI QA pass and was then restored. The process was closed
through the game exit confirmation before restore.

## Final run

- The Korean main menu showed the title, `언어 / 한국어`, all available menu
  buttons, and the patch footer without clipping or overlap.
- The first game screen loaded the coffee-shop background from the current
  archive and rendered Korean dialogue with a valid Korean font.
- The next dialogue line wrapped to two lines and remained inside the dialogue
  box; no clipping or overflow was observed.
- The settings layout previously verified on this payload had no duplicate
  language row and no voice-slider/footer collision.
- Fresh final-run `log.txt` contains no uncaught exception. The only warning is
  the expected Steam API initialization message caused by launching the EXE
  directly rather than through Steam.

## Diagnosis and fix exercised

The first runtime pass exposed an old loose `scripts/content/background.rpy`
declaration requesting `bg/coffee/bg_coffee_1.jpg`, while the current archive
contains the `.webp` asset. The release was rebuilt to remove that stale file
and its compiled sidecar only when their recorded legacy hashes match; the
corresponding `bgm.rpy`/`.rpyc` pair is handled the same way. A second install
then loaded the current coffee-shop background successfully.

The quick-menu labels `AUTO`, `SKIP`, `SAVE`, `LOAD`, `LOG`, and `SYS.` remain
original English UI text. This is recorded as a scope note, not a rendering
failure.

The adjacent `runtime-final-traceback.txt` is an older artifact from the
earlier backup-inside-`game/` duplicate-label experiment. Its timestamp
predates the final run; it was not regenerated by the final run.
