## T.K.PUNK (삼국 펑크) 한글 패치 v1.0.0

중국어 원문을 기준으로 본문, 스토리, UI와 이미지형 문구를 한국어로 옮긴 첫 공개 배포본입니다.

### 주요 내용

- 기본 언어표 고유 문구 3,923개
- 스토리 고유 문구 24,832개
- 내장 다국어 문구 2,586개
- 추가 프리팹 라벨 146개
- 이미지형 UI 53개
- 한글 타이틀 로고와 글꼴
- 자동 원본 백업 및 원상 복구

### 설치

`TKPUNK_KoreanPatch_v1.0.0.zip`을 완전히 푼 뒤 `INSTALL_KOREAN_PATCH.bat`을 실행하세요.

이 배포본은 게임 원본을 포함하지 않으며, 정품 게임의 지원 버전에서 변경분을 재구성합니다. 지원하는 원본 `app.asar`의 SHA-256은 다음과 같습니다.

`D6F10010E181672B1D1A444BBF500035336D3B35E6D8EE26F7A9ADAC0AB6A09A`

### 알려진 제한

- 튜토리얼 영상 51개의 중국어 UI는 영상 자체에 포함되어 있습니다.
- 일부 배경 간판과 세계관 장식 문자는 원작 미술을 유지했습니다.

자세한 설치 및 복구 방법은 [게임별 안내](https://github.com/BK927/korean-game-patches/tree/main/games/tkpunk)를 참고하세요.
