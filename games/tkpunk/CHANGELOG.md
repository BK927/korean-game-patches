# 변경 내역

## v1.1.0

- 게임 빌드 `1.0.260821.1` 대응
- 신규 업데이트 내역 4건과 CG 감상 메뉴 번역
- 신규·개정 스킬 및 업적 문구 번역
- 개발사가 수정한 스토리 문장 100개를 새 중국어 원문 기준으로 재번역
- 기존 인명·전투 용어·등장인물 말투 교차 검수
- 변경된 Cocos 자산 해시를 자동 추적하도록 빌드 절차 개선
- 버전별 원본 백업을 사용해 이전 패치 백업과 충돌하지 않도록 설치·복구 도구 개선
- 새 원본 기준 VCDIFF 재생성 및 복원 해시 검증
- 실제 게임 첫 화면과 메인 메뉴 실행 검증

## v1.0.0

- 중국어 원문 기준 전체 텍스트 번역
- 스토리 대사와 선택지 번역
- 내장 다국어 데이터와 프리팹 라벨 번역
- 한글 글꼴 적용
- 이미지형 UI 53개 재제작
- 타이틀 로고 `삼국 펑크`와 부제 `사랑과 파괴의 신` 적용
- 원본 해시 확인, 자동 백업과 복구 기능이 있는 설치 도구 추가
- 실제 게임 첫 화면과 메인 메뉴 실행 검증
