# 奇迹一刻 Surmount 한글 패치

![한국어 타이틀](assets/title-ko.png)

중국어 원문을 기준으로 제작한 비공식 한국어 패치입니다. 게임의 번체 중국어 언어 슬롯을 한국어로 교체하며, 본편 스토리와 시스템 문구, 주요 이미지형 UI, 한글 표시용 글꼴을 함께 적용합니다.

## v0.1.0 적용 범위

- 설정·데이터용 고유 문구 9,790개
- 별도 본편 스토리 표시 문장 10,648개
- 화면 UI 문구 478개 문맥 재검수
- 게임 설정표의 대사·시스템 텍스트 9,367행
- 타이틀·시작 메뉴·새 게임·저장/불러오기·대화 메뉴·시스템 설정 이미지 72개
- 시작 메뉴의 긴 한국어가 잘리지 않도록 스프라이트 표시 영역 10개 보정
- 한글 완성형 11,172자를 포함한 고정형 한글 글꼴 4종

인명·팀명·길드명·직업·전술 용어는 공통 용어집으로 통일했습니다. 게임 안의 SNS 사용자명과 `@handle`, 스크립트 제어 태그와 변수는 원문 형식을 유지합니다.

## 지원 환경

- 플랫폼: Windows / Steam
- Steam AppID: `1089630`
- 지원 빌드: `8856270`
- 대상 파일: `Surmount_Data/resources.assets`
- 원본 SHA-256: `2B2AD7B0829A612269D6692B6FEC082DCA8D4EF2E6E7CA853F534FA111ECD169`

원본 해시가 다르면 설치를 중단합니다. 게임이 업데이트된 경우 Steam 무결성 검사 후 새 빌드 대응 패치를 기다려 주세요.

## 설치 방법

1. [Releases](https://github.com/BK927/korean-game-patches/releases)에서 `Surmount-Korean-Patch-v0.1.0-build8856270.zip`을 받습니다.
2. 원하는 폴더에 압축을 완전히 풉니다.
3. 게임을 종료합니다.
4. `INSTALL_KOREAN_PATCH.bat`을 실행합니다.

설치 프로그램은 Steam 라이브러리에서 게임을 찾고, 대상 파일의 원본 해시를 확인한 뒤 같은 폴더에 `resources.assets.koreanpatch-original`로 백업합니다. 설치 후에는 결과 파일의 SHA-256을 다시 검사하고 게임 언어를 한국어 슬롯으로 설정합니다.

자동으로 게임을 찾지 못하면 PowerShell에서 게임 폴더를 직접 지정할 수 있습니다.

```powershell
.\install.ps1 -GameDir "D:\SteamLibrary\steamapps\common\Surmount"
```

## 원상 복구

게임을 종료한 뒤 `RESTORE_ORIGINAL.bat`을 실행합니다. 백업 파일을 되돌린 다음 지원 원본의 SHA-256과 일치하는지 검사합니다. 백업이 없으면 Steam의 설치 파일 무결성 검사를 이용하세요.

## 알려진 제한

- 튜토리얼 예시 화면 26개는 중국어 UI가 이미지에 새겨져 있어 원작 이미지를 유지했습니다.
- 일부 장식과 캐릭터 명찰 이미지에는 중국어가 남아 있을 수 있습니다.
- 게임 업데이트로 `resources.assets`가 바뀌면 새 버전 대응이 필요합니다.

플레이에 필요한 본편 스토리·선택지·설정·주요 메뉴는 한국어화했습니다.

## 배포 형식

게임 원본 파일 전체는 포함하지 않습니다. Xdelta(VCDIFF) 변경분과 설치·복구 도구만 제공하며, 사용자가 보유한 정품 원본에서 한국어 파일을 재구성합니다.
