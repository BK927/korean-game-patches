## 奇迹一刻 Surmount (기적의 순간) 한글 패치 v0.1.0

중국어 원문을 기준으로 본편 스토리와 시스템 문구, 주요 이미지형 UI를 한국어화한 첫 배포판입니다.

### 적용 범위

- 설정·데이터용 고유 문구 9,790개와 본편 스토리 표시 문장 10,648개 번역
- UI 문구 478개 별도 문맥 재검수
- 인명·팀명·길드명·직업·전술 용어와 등장인물 말투 일관성 검수
- 타이틀·시작 메뉴·새 게임·저장/불러오기·대화 메뉴·시스템 설정 이미지 72개 한국어 재조판
- 한글 글꼴 4종 적용과 긴 메뉴 표시 영역 10개 보정
- 원본·설치 결과 해시 검사와 자동 백업·복구 지원
- 실제 게임에서 한국어 타이틀, 주요 메뉴, 새 게임과 본편 대사 표시 확인

### 설치

`Surmount-Korean-Patch-v0.1.0-build8856270.zip`을 완전히 푼 뒤 `INSTALL_KOREAN_PATCH.bat`을 실행하세요.

지원하는 Steam 빌드는 `8856270`이며, 원본 `Surmount_Data/resources.assets`의 SHA-256은 다음과 같습니다.

`2B2AD7B0829A612269D6692B6FEC082DCA8D4EF2E6E7CA853F534FA111ECD169`

### 알려진 제한

- 튜토리얼 예시 화면 26개에는 이미지에 새겨진 중국어 UI가 남아 있습니다.
- 일부 장식과 캐릭터 명찰 이미지는 원작 미술을 유지했습니다.

자세한 설치와 복구 방법은 [게임별 안내](https://github.com/BK927/korean-game-patches/tree/main/games/surmount)를 참고하세요.
