# 새 게임 패치 추가 규칙

새 게임은 `games/_template`을 복사한 뒤 폴더 이름을 영문 소문자 slug로 변경합니다.

## 필수 항목

1. 게임명과 스토어 링크
2. 지원하는 게임 버전 또는 원본 파일 SHA-256
3. 패치 버전과 변경 내역
4. 설치·복구 방법
5. 알려진 미번역 요소
6. 원본 파일을 포함하지 않는 배포 형식
7. 실제 게임 실행 검증 결과

## 버전 규칙

- 게임별 태그: `게임-slug/v1.0.0`
- 배포 파일: `게임-slug_KoreanPatch_v1.0.0.zip`
- 호환되지 않는 게임 업데이트가 나오면 새 패치를 별도 릴리스로 게시합니다.

## 권장 폴더

```text
games/<slug>/
├─ README.md
├─ assets/
├─ installer/
└─ manifest.json
```
